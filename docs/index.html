ReadQraft

FASTQ QC and trimming without terminal fear.

ReadQraft runs locally on your computer so your sequencing reads stay private. This GitHub Pages site is for documentation, screenshots, downloads, and demo explanation only. It does not run FastQC in the browser.

Simple Mode

FastQC [checks sequencing read quality], fastp [adapter and quality trimming], post-trim FastQC, MultiQC [combined QC summary], and reproducibility ZIP.

Advanced Mode

Control Phred quality threshold [base-call confidence cutoff], minimum read length [shortest read kept after trimming], adapters, threads, and logs.

Reproducibility

Commands, tool versions, checksums, manifest, methods text, session info, and logs are recorded for every analysis.
