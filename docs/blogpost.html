ReadQraft 0.1.0 MVP

FASTQ QC and trimming without terminal fear.

ReadQraft is a privacy-preserving desktop app for sequencing read quality control, trimming, MultiQC reporting, and reproducibility documentation on macOS and Windows.

Why ReadQraft Exists

Many biologists need reliable FASTQ quality control [checking raw sequencing read quality] and adapter trimming [removing leftover sequencing adapter sequences], but the command line can make a routine QC task feel risky. ReadQraft wraps established bioinformatics tools in a local desktop workflow while preserving proper scientific terminology.

Reads stay local. ReadQraft runs on the user’s computer. FASTQ files are not uploaded to a cloud service.

What The MVP Does

Raw QC

FastQC [checks sequencing read quality] runs before trimming.

Trimming

fastp is used where available; Cutadapt provides a Windows-native fallback.

Combined Reports

MultiQC [combines QC reports into one summary] aggregates reports.

Reproducibility

Commands, versions, checksums, logs, methods text, and manifests are packaged for publication workflows.

Designed For Clarity, Not Oversimplification

The interface uses real terms such as Phred quality threshold [base-call confidence cutoff], minimum read length [shortest read kept after trimming], and paired-end reads [R1 and R2 read files from the same sample]. ReadQraft explains terms without replacing them with vague metaphors.

Platform Strategy

ReadQraft bundles a local tool environment with the desktop app. macOS builds include FastQC, fastp, Cutadapt, MultiQC, and OpenJDK. Windows builds use FastQC, Cutadapt, MultiQC, Python, and OpenJDK because native Windows fastp packages are not currently available through Bioconda. Every run records the actual trimming engine used.

What Comes Next

The next milestones are Windows installer verification, signed and notarized releases, deeper report parsing, tool setup UI polish, and example datasets. The MVP already demonstrates the core promise: local FASTQ QC, trimming, reports, and reproducibility documentation without requiring users to run terminal commands after installation.

ReadQraft is open source. See the repository README for setup, packaging, and development details.
