ReadQraft 0.1.0 is live

FASTQ QC should not require terminal courage.

ReadQraft is a local desktop application for FASTQ quality control, trimming, MultiQC reporting, and reproducibility packages. It is built for biologists who need rigorous sequencing QC without turning every analysis into a command-line exam.

Why This Matters

The terminal should not be the gatekeeper for good sequencing practice.

FASTQ QC is not optional housekeeping. It is the first checkpoint between expensive sequencing and every downstream biological claim. If quality control is intimidating, skipped, inconsistently documented, or trapped in a lab member’s shell history, the science becomes harder to trust and harder to reproduce.

Accessibility without dilution

ReadQraft keeps real terms like Phred quality threshold [base-call confidence cutoff] and explains them in place, instead of hiding the science behind vague labels.

Privacy by default

Sequencing reads can be sensitive. ReadQraft runs locally on macOS and Windows so data does not need to leave the lab computer for routine QC and trimming.

Reproducibility baked in

Every run records commands, tool versions, parameters, checksums, logs, methods text, and a manifest. The point is not just to get clean reads, but to know exactly how they were produced.

ReadQraft is for the moment when someone has real sequencing data, real scientific questions, and one very understandable thought: “I do not want to break this by typing the wrong command.”

The Problem

Routine QC is too often fragile, invisible, or person-dependent.

A typical FASTQ workflow asks users to remember tool names, command flags, file-pairing conventions, output folders, thread counts, report locations, and version capture. Experienced bioinformaticians can manage that. But many labs rely on students, technicians, collaborators, or occasional users who need the same rigor without the same terminal fluency.

The result is a quiet reproducibility gap. Two people can process the same reads with slightly different parameters. A methods section can say “reads were trimmed” without preserving the exact command. A missing R2 file can become a downstream mystery. A failed tool can look like a wall of terminal noise instead of a fixable setup problem.

ReadQraft is designed to make the careful path the easy path: select files, confirm detected pairs, choose Simple Mode or Advanced Mode, run local tools, watch progress, and download a reproducibility package.

What It Does

Publication-grade outputs from a desktop workflow.

The MVP wraps established tools while keeping the workflow local and inspectable.

Quality checks

FastQC [checks sequencing read quality] runs on raw and trimmed reads.

Trimming engines

macOS uses fastp where available. Windows uses Cutadapt as the native trimming path when fastp is not available.

Combined reports

MultiQC [combines QC reports into one summary] creates a single project-level QC report.

Methods text

ReadQraft generates a methods paragraph from the actual tools, versions, and parameters used.

Checksums

Input and output SHA256 checksums help confirm file integrity and support reproducible handoff.

Logs and manifests

Command logs, version logs, session info, and manifest JSON are saved automatically.

Open Source MVP

Try it, inspect it, and help shape it.

ReadQraft 0.1.0 is an MVP source release. The next milestones are verified Windows installer artifacts, signed macOS builds, deeper report parsing, and a smoother tool setup experience. The foundation is now public: a local desktop FASTQ QC workflow that treats beginner-friendliness and scientific accuracy as partners, not opposites.
